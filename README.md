# 법인대출 심사 PoC

기업 여신의 비대면 심사 구조를 시연하는 웹페이지입니다. 심사 업무별 필요 자료·담당·판단 기준·전결권자를 온톨로지로 연결하고 대출 상품·신청인·기업 조건에 따라 심사 절차를 구성합니다.

| 항목 | 내용 |
|---|---|
| 시연 페이지 | https://kjhoeakjy.github.io/nice/ |
| 구상안 | [docs/구상안.md](docs/구상안.md) |
| 실행 환경 | 브라우저 (서버·외부 라이브러리 불필요, `index.html` 단일 파일) |
| 데이터 | 기업 정보는 DART 공시 정보, 은행 내부 정보는 가상 데이터 |

## 화면 구성

| 화면 | 기능 |
|---|---|
| 업무 현황 | 시연 구성 안내, 심사 건, 만기 도래 여신 |
| 심사 온톨로지 | 심사 업무별 필요 자료·제출 방식·추가 요청 자료·담당·판단 기준·전결권자 연결 구조, 상품·신청인·기업 정보·신청 금액 조건별 절차 구성, 선택 조건의 가상 신청 건 생성 |
| 기업 정보 | 기업개황, 별도·연결 재무제표, 차입금 구성, 공시 목록, 관계 정보 |
| 심사 화면 | 신청 정보 확인, 심사 절차·필요 자료 확인, 재무지표 산출, 상환능력 분석, 정보가치 기반 추가 확인 항목 선택, 추가 자료 요청·승인 |
| 실행 여신 | 여신 내역, 이자 납입 내역, 약정 점검, 만기연장 심사 개시 |
| 사후 모니터링 | 공시·사채 만기 사건과 여신 연결, 검토 업무 생성·종결 |
| 모델 설명 | 모델 구조, 심사 온톨로지, 자료 검증, 재무·상환능력 분석, 정보가치 기반 추가 확인 선택, 가정과 한계 |
| 고객 화면 | 요청 자료 제출 |

| 사용자 | 역할 |
|---|---|
| 김연주 | 심사역 |
| 이준호 | 심사팀장 (전결 한도 30억 원) |
| 최민수 | 고객 (다산솔루에타 재무팀장) |

진행 상태는 브라우저 `localStorage`에 저장됩니다. 상단 `초기화` 버튼을 두 번 누르면 초기 상태로 복원됩니다.

## 폴더 구조

```
index.html            배포 파일 (build.py 생성, GitHub Pages 게시 대상)
build.py              빌드 스크립트
src/
  index.html          페이지 틀 (마크업, 포함 지시문)
  styles/
    fonts.css         글꼴 선언
    base.css          기본 레이아웃·구성 요소
    theme.css         색상
    skin.css          업무 시스템 스타일, 반응형
  fonts/              Wanted Sans (400·500·600·700)
  data/
    dart.json         DART 공시 정보 (2개사)
    seed.js           가상 데이터 (사용자, 내규, 신청 건, 여신, 업무 패키지)
  js/
    creditos.js       공통 기능 (계산·검증·시뮬레이션·의사결정)
    app.js            화면, 경로 처리, 업무 처리, 상태 저장
docs/                 구상안, 설계·데이터·기능·개발 문서
```

## 빌드

```
py build.py           # index.html 생성
py build.py --check   # index.html 과 src/ 의 일치 여부 확인
```

Python 3 표준 라이브러리만 사용합니다. `src/` 수정 후 `index.html` 을 다시 생성하고 함께 커밋합니다.

## 유의 사항

| 항목 | 내용 |
|---|---|
| 가정값 | 위험 신호 점수, 구간별 부도확률, 민감도·특이도, 고객 이탈률·처리비용, 자금조달금리, 보증 비율 (모델 설명 화면) |
| 위험 신호 | 설명용 규칙, 신용평가모형 아님 |
| 상품별 내규 | 보증부대출·부동산담보대출의 확인 기준과 현장 확인 여부는 가상은행 내규. 실제 은행 내규·법적 기준 아님 |
| 현장 확인 | 확인 근거 문구만 기록, 실제 실사 연계 없음 |
| 적용 범위 | 데이터로 정의한 규칙에 따른 절차 구성. 실제 은행 시스템 연계, 법규 검증, 범용 지식 그래프 기능 미포함 |
| 자료 제출 | 파일명만 기록, 파일 내용 전송 없음 |
| 글꼴 | [Wanted Sans](https://github.com/wanteddev/wanted-sans), SIL Open Font License 1.1 |
