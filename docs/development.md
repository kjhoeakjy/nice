# 개발 방법

## 준비

- Python 3 (표준 라이브러리만 사용). Windows 는 `py`, macOS·Linux 는 `python3`.
- 브라우저. 별도 서버나 Node.js 는 필요 없습니다.

## 수정 → 빌드 → 확인

1. `src/` 아래 파일을 수정합니다. 루트의 `index.html` 은 결과물이므로 직접 고치지 않습니다.
2. `py build.py` 로 `index.html` 을 다시 만듭니다.
3. `index.html` 을 브라우저로 열어 확인합니다(파일을 더블클릭해도 됩니다).
4. `src/` 와 `index.html` 을 함께 커밋합니다. 커밋 전에 `py build.py --check` 로 둘이 일치하는지 확인할 수 있습니다.

## build.py 동작

`src/index.html` 을 읽어 두 가지 지시문을 바꿉니다.

| 지시문 | 처리 |
|---|---|
| `@@include <경로>@@` | 파일 내용을 그대로 넣습니다. CSS 안의 `url(../fonts/*.woff2)` 는 `data:font/woff2;base64,...` 로 인라인합니다. |
| `@@json <경로>@@` | JSON 파일을 읽어 한 줄(compact, `ensure_ascii=False`)로 넣습니다. |

경로는 `src/` 기준입니다. 결과는 줄바꿈 LF, UTF-8 로 저장합니다.
분리 직후의 `src/` 로 빌드한 결과는 분리 전 `index.html` 과 바이트 단위로 같습니다.

## 파일을 추가할 때

- 새 CSS 나 스크립트 파일을 만들면 `src/index.html` 의 알맞은 위치에 `@@include ...@@` 줄을 넣습니다.
- 스크립트 순서: 데이터(`CREDITOS_DATA`, `CREDITOS_SEED`) → `creditos.js` → `app.js`. 뒤 파일이 앞 파일의 전역 값을 씁니다.
- CSS 는 뒤에 오는 파일이 앞 파일을 덮어씁니다. 색은 `theme.css` 의 `:root` 변수에서, 밀도·반응형은 `skin.css` 에서 바꿉니다.

## 배포

GitHub Pages 가 `main` 브랜치 루트의 `index.html` 을 게시합니다(https://kjhoeakjy.github.io/nice/). `main` 에 push 하면 몇 분 안에 반영됩니다.

## 확인해 볼 시나리오

1. 심사역(김연주)으로 `업무 현황` → 신청 건 `APP-2026-0412` 열기.
2. 자료 검증, 대표권 확인(신청인이 재무팀장이라 위임장 필요), 상환여력 시나리오, 다음 업무 추천을 차례로 확인.
3. 위임장 등 자료 요청 → 사용자를 고객(최민수)으로 바꿔 `요청 자료 제출` → 다시 심사역으로 돌아와 확인 완료.
4. 의견 기록 후 심사팀장(이준호)으로 바꿔 결정.
5. `실행 여신` → `LN-2025-0187` 만기연장 심사 시작, `사후 모니터링` 에서 사건을 과제로 등록·종결.
6. `처리 기록`, `업무 기능 관리` 에서 Action 기록과 함수 호출 기록 확인.

`초기화`를 두 번 누르면 처음 상태로 돌아갑니다.
