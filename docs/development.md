# 개발 절차

## 실행 환경

| 항목 | 내용 |
|---|---|
| 빌드 | Python 3 표준 라이브러리 (Windows `py`, macOS·Linux `python3`) |
| 실행 | 브라우저 (서버·Node.js 불필요) |

## 수정·빌드·확인

| 단계 | 내용 |
|---|---|
| 수정 | `src/` 하위 파일 수정. 루트 `index.html` 은 빌드 결과물이므로 직접 수정 금지 |
| 빌드 | `py build.py` |
| 확인 | 루트 `index.html` 을 브라우저로 열어 화면 확인 |
| 커밋 | `src/` 와 `index.html` 동시 커밋. 사전 점검은 `py build.py --check` |

## 빌드 방식

`src/index.html` 의 지시문을 치환하여 루트 `index.html` 을 생성합니다.

| 지시문 | 처리 |
|---|---|
| `@@include <경로>@@` | 파일 내용 삽입. CSS 의 `url(../fonts/*.woff2)` 는 `data:font/woff2;base64,...` 로 내장 |
| `@@json <경로>@@` | JSON 을 한 줄 형식(`ensure_ascii=False`)으로 삽입 |

| 항목 | 기준 |
|---|---|
| 경로 기준 | `src/` |
| 출력 형식 | UTF-8, 줄바꿈 LF |
| 검증 | 파일 분리 시점의 빌드 결과와 분리 전 `index.html` 의 바이트 단위 일치 확인 |

## 파일 추가

| 대상 | 방법 |
|---|---|
| CSS·스크립트 | `src/index.html` 의 해당 위치에 `@@include ...@@` 행 추가 |
| 스크립트 순서 | 데이터(`CREDITOS_DATA`, `CREDITOS_SEED`), `creditos.js`, `app.js` 순 |
| 색상 변경 | `theme.css` 의 `:root` 변수 |
| 밀도·반응형 변경 | `skin.css` |

## 배포

GitHub Pages 가 `main` 브랜치 루트의 `index.html` 을 게시합니다(https://kjhoeakjy.github.io/nice/). `main` 반영 후 수 분 내 적용됩니다.
